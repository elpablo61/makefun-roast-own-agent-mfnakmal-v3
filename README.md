A make.fun entry for [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda): one line, roasting my own AI agent — playful, never hateful.

`main.ts` (Node 22) writes exactly one roast line, 1–140 characters, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The roast

> My agent wrote a 4,000-word status report about a one-line roast that ranked #1,137.

## Run

```sh
node main.ts
cat /output/entry.txt
```
